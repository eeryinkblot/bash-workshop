# Homework 03: Variablen

1. Erstelle Variablen mit und ohne Leerzeichen im Wert.
2. Vergleiche Single Quotes und Double Quotes.
3. Recherchiere, was `export` mit der Umgebung von Kindprozessen macht.
4. Erstelle ein Array und gib alle Elemente einzeln aus.

Startpunkt:

```bash
name="Ada Lovelace"
echo "$name"
echo '$name'
items=(one two "three four")
printf '<%s>\n' "${items[@]}"
```
