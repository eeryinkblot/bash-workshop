# Homework 01: Mentales Modell

1. Untersuche mit `type` mindestens zehn Befehle, die du regelmäßig nutzt.
2. Sortiere sie in Builtin, Programm, Alias oder Funktion.
3. Prüfe mit `command -v`, wo Programme liegen.

Beispiel:

```bash
type cd
type ls
type git
type test
type printf
command -v git
```
