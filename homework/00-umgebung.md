# Homework 00: Umgebung

1. Finde heraus, welche Bash-Version du verwendest.
2. Prüfe, ob dein Terminal beim Start direkt Bash öffnet oder eine andere Shell.
3. Notiere den Unterschied zwischen `echo "$SHELL"` und `echo "$BASH_VERSION"`.

Hilfsbefehle:

```bash
echo "$SHELL"
echo "$BASH_VERSION"
ps -p $$
```
