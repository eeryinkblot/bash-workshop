# Homework 06: Skripte, Startup, PATH und source

1. Erzeuge ein kleines Skript mit Shebang.
2. Mache es ausführbar.
3. Starte es mit `./scriptname`.
4. Prüfe, warum es ohne `./` nicht gefunden wird.
5. Erstelle eine Datei, die eine Variable setzt, und vergleiche `bash datei` mit `source datei`.

Hinweis: Startup-Dateien wie `~/.bashrc` nur lesen, nicht im Rahmen der Homework verändern.
