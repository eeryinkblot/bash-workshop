# Homework 04: Funktionen und Befehlsarten

1. Schreibe eine Funktion `greet`, die einen Namen annimmt.
2. Schreibe eine Funktion, die mit `local` arbeitet.
3. Lege einen Alias an und entferne ihn wieder.
4. Untersuche mit `type`, was Bash jeweils aufrufen würde.

Startpunkt:

```bash
greet() {
  echo "Hallo $1"
}

greet Tony
```
